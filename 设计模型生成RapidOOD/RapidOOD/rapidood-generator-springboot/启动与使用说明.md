# RapidOOD Generator — 启动与使用说明

> 将 `.remodel` 需求模型文件通过 ATL 变换生成 `.cd` 类图文件（PlantUML 子集 + Xtext 格式），无需 Eclipse 运行。

---

## 一、环境要求

| 工具 | 版本要求 |
|------|----------|
| JDK | **17**（必须，JPMS 相关） |
| Maven | 3.8+ |
| 网络 | 首次构建需访问 Maven Central / Eclipse Orbit |

---

## 四、输入文件

### 格式

输入为 **RM2PT 需求模型文件**，扩展名 `.remodel`，由 RM2PT Eclipse 插件生成。

### 位置

输入文件放在**本机任意位置**，调用 API 时传递其**绝对路径**即可。

工程内置的测试样例（ATM 银行系统）：

```
rapidood-generator-transform/src/test/resources/testdata/atm.remodel
```

完整路径：
```
/Users/yuanyaowu/Desktop/实验室材料/rapidOOD/设计模型生成RapidOOD/RapidOOD/rapidood-generator-springboot/rapidood-generator-transform/src/test/resources/testdata/atm.remodel
```

## 五、输出文件

### 格式

输出为 **Xtext ClassDiagram 文本**，扩展名 `.cd`，内容为 PlantUML 子集语法：

```
@startuml
class ATM {
  cardNumber : String
  withdrawCash(amount : Integer) : Boolean
}
ATM -- BankCardRepository : owns
@enduml
```

### 位置规则

默认遵循与 Eclipse 插件相同的约定：

```
输入文件所在目录/
└── DesignModel/
    └── {与输入同名}.cd    ← 自动创建
```

**示例：**

| 输入 | 输出 |
|------|------|
| `/workspace/ATM/ATM.remodel` | `/workspace/ATM/DesignModel/ATM.cd` |
| `/data/CoCoME.remodel` | `/data/DesignModel/CoCoME.cd` |

> 若 `DesignModel/` 目录不存在，服务会自动创建。

## 六、API 使用

### 6.1 Swagger UI（推荐）

浏览器访问：[http://localhost:8080/swagger-ui.html](http://localhost:8080/swagger-ui.html)

在 `POST /api/v1/generate/class-diagram` 接口中填写 `inputPath` 后点击 **Execute**。

---

### 6.2 curl

#### 最常用：只传输入路径，输出自动放 DesignModel/

```bash
curl -s -X POST http://localhost:8080/api/v1/generate/class-diagram \
  -H "Content-Type: application/json" \
  -d '{
    "inputPath": "/绝对路径/你的模型.remodel"
  }' | python3 -m json.tool
```

#### 指定输出目录

```bash
curl -s -X POST http://localhost:8080/api/v1/generate/class-diagram \
  -H "Content-Type: application/json" \
  -d '{
    "inputPath": "/绝对路径/你的模型.remodel",
    "outputDir": "/绝对路径/输出目录"
  }'
```

#### 使用内置 ATM 样例快速体验

```bash
curl -s -X POST http://localhost:8080/api/v1/generate/class-diagram \
  -H "Content-Type: application/json" \
  -d '{
    "inputPath": "/Users/yuanyaowu/Desktop/实验室材料/rapidOOD/设计模型生成RapidOOD/RapidOOD/rapidood-generator-springboot/rapidood-generator-transform/src/test/resources/testdata/atm.remodel"
  }' | python3 -m json.tool
```

## 七、配置说明

配置文件：`rapidood-generator-api/src/main/resources/application.yml`

```yaml
server:
  port: 8080                       # 服务端口

rapidood:
  paths:
    input-file: /data/rapidood/input/CoCoME.remodel  # 默认输入（请求体未传时使用）
    output-dir: /data/rapidood/output/DesignModel    # 默认输出目录（output-follow-input=false 时）
    output-follow-input: true      # true = 输出放在输入文件的 DesignModel/ 子目录（推荐）
```

> 修改配置后需重启服务。也可在启动时通过命令行参数覆盖：
> ```bash
> mvn spring-boot:run -pl rapidood-generator-api -am \
>   -Dspring-boot.run.arguments="--rapidood.paths.input-file=/my/path/Model.remodel"
> ```

## 九、模块结构

```
rapidood-generator-springboot/
├── pom.xml                          # 父 POM（Spring Boot 3.2 + Java 17）
│
├── rapidood-requirement-model/      # REMODEL EMF（从 RM2PT JAR 解包）
├── rapidood-classdiagram-model/     # ClassDiagram Xtext DSL + src-gen
├── rapidood-generator-core/         # EmfRegistryConfig（单例 EMF 注册）
│
├── rapidood-generator-transform/    # ★ 核心变换层
│   ├── AtlTransformService          #   .remodel → .cd（ATL 无头执行）
│   ├── DesignGenerateService        #   编排：校验 + 变换 + 读取文本
│   └── GenerateResultDto            #   返回 inputPath/outputPath/cdContent
│
├── rapidood-generator-api/          # ★ REST 服务层
│   ├── GenerateController           #   POST /api/v1/generate/class-diagram
│   ├── GlobalExceptionHandler       #   统一错误 JSON
│   ├── RapidoodPathProperties       #   rapidood.paths.* 配置绑定
│   └── application.yml
│
└── scripts/
    └── generate-classdiagram-src-gen.sh   # 重新生成 Xtext src-gen（grammar 变更时用）
```
